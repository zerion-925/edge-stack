# Product

## Register

product

## Users

TypeScript developers who want a reliable Cloudflare-first starting point. They inspect the template, run it locally, and extend one proven vertical slice.

## Product Purpose

Edge Stack demonstrates clear boundaries between browser state, API contracts, Workers, and background work. Success means a developer can run, test, and adapt it without first removing speculative infrastructure.

## Brand Personality

Precise, calm, and practical. The interface should feel trustworthy and direct.

## Anti-references

Avoid generic SaaS dashboards, ornamental gradients, excessive cards, invented controls, and decoration that hides the architecture.

## Design Principles

1. Make the data flow visible.
2. Prefer familiar controls and plain language.
3. Show useful states, including loading, empty, offline, and errors.
4. Keep architecture proof close to the interaction that exercises it.

## Accessibility & Inclusion

Target WCAG 2.2 AA. Support keyboard navigation, visible focus, reduced motion, and color-independent status cues.
