# Design System

## Theme

A restrained light product interface for developers working on bright desktop displays, with a responsive single-column layout on small screens.

## Color

Use tinted OKLCH neutrals and one green accent for actions and active state. Reserve red for errors and amber for offline state.

## Typography

Use the system sans-serif stack. Use a compact fixed scale and keep prose below 70 characters per line.

## Layout

Use a narrow application shell, a strong top bar, and open sections separated by whitespace or single-pixel rules. Avoid nested cards.

## Components

Use consistent rounded controls with visible hover, focus, disabled, loading, and error states. Skeleton rows represent loading.

## Motion

Use 180 ms opacity and transform transitions for state changes. Disable non-essential motion when reduced motion is requested.
